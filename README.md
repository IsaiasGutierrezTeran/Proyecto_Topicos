# Proyecto Integrador - Topicos y Programacion Avanzada

## Sistema Web de Analisis de Sentimientos con NLP

Aplicacion web para clasificar sentimientos en resenas
escritas en espanol mediante procesamiento de lenguaje
natural y modelos de machine learning.

## Integrantes

## Tecnologias previstas
- Python
- FastAPI
- scikit-learn
- NLTK
- HTML, CSS y JavaScript

## Estructura
- data: datasets
- notebooks: analisis exploratorio
- src/nlp: preprocesamiento de textos
- src/models: entrenamiento y evaluacion
- api: backend
- frontend: interfaz web
- tests: pruebas
- docs: informe tecnico
